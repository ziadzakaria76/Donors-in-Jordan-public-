#     pip install -r jordan_tender_monitor/requirements-dev.txt

# running and the suite goes green having skipped them -- so a test asserts
# that tests.yml installs it.

# matched the FIRST JTM_OUTPUT_FORMATS in monitor.yml -- the diagnose step,
# which writes markdown only -- and passed while the step that matters wrote no
# JSON at all. Parsing the file is the fix.
